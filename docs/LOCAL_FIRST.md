# 本地优先同步

客户端先显示已保存的派生副本，联网后再按真实身份与版本追平。原生存档仍是历史事实来源，本地草稿独立于可丢弃缓存。

## 身份和版本

副本绑定服务器、根目录、提供方、运行实例、终端和会话身份。相同标题或目录字符串不能证明是同一会话。异步读取完成时再次核对目标和历史代次，旧请求不能替换当前窗口。

服务端维护快照与增量，客户端核对序号和基线。基线失配时读取完整快照；重连不清空草稿，不重放消息、按键或其他写操作。

## 阅读与草稿

每个窗口保存自己的草稿、展示模式、选择和阅读位置。切换服务器或会话时先保存，再从对应命名空间恢复。缓存损坏可以丢弃正文投影，不能连带删除草稿。

历史按需有界读取。用户阅读旧内容时，新数据继续进入副本，不强制贴底；明确返回最新后才更新阅读位置。工具详情与文件内容独立加载，取消或迟到结果不影响当前会话。

## 连接与终端

状态同步、原生观察和消息投递是不同通道，分别报告状态。对端关闭或服务重启后按既有退避恢复；认证失败要求修复连接，不无限重试。

隐藏终端继续解析必要增量但不绘制。重连和观察不取得焦点或尺寸，缓存命中切换不等待网络。资源限制与真实运行时验证要求见[共享运行时约束](SHARED_RUNTIME_ARCHITECTURE.md)。
