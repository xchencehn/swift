# 产品规范

## 范围与连接

Swift 是开源的服务器与客户端工具，连接 Herdr 中的真实终端和 Agent 会话。产品不提供中转、Swift 账号、订阅、配对或独立任务管理系统。

同一系统和本机 Windows/WSL 免认证。其他局域网连接使用服务器持久 token，`swift` 显示可直接粘贴到客户端的链接。客户端将 token 与普通连接元数据分开保存。错误或过期凭据要求修复连接，不持续伪装成重连中。

原生客户端启动时恢复上次会话，初始恢复失败时显示服务器选择页；已经打开的会话遇到后续网络中断时保留本地视图。服务器选择页突出当前窗口或上次连接，点击其他服务器名称直接连接；较多连接支持本地名称与地址搜索。编辑、新窗口和移除操作位于各服务器的菜单；移除前明确确认只删除本机连接。添加与编辑只输入完整连接链接和可选名称，无需选择连接类型；输入旁说明本机及Windows/WSL免认证。认证失效时更新既有连接链接，保留连接身份与草稿。

原生客户端可保存多条直连连接。升级保留已有连接身份；切换服务器不删除该窗口的草稿、阅读位置或展示偏好。移除连接只影响本地配置，不停止服务器上的终端。

## 会话与消息

Herdr 的 Workspace、Tab、Pane 和 Terminal 是运行时身份来源。界面以 Tab 为主要操作单位，创建、重命名、排序、关闭和工作区操作调用原生能力；不按名称或目录推断身份。

结构化聊天只显示经过身份核验的原生存档消息，不生成冒充原生历史的发送气泡。各提供方独立渲染消息和工具，公共容器复用布局、滚动和交互。临时会话使用同一原生进程提供的数据，不伪造持久存档。

消息投递与原生设置沿用请求身份和操作收据。结果不确定时查询既有结果，不自动重新发送。显式操作前按当前原生输入版本处理草稿；观察不清空输入或发送命令。

消息导航按已知用户消息显示可点击的圆点，支持预览、键盘、早期消息分页和返回最新。导航只读取并定位正文，不发送消息，不取得原生焦点或尺寸。

## 终端与窗口

结构化模式和终端模式按窗口独立保存；Shell 显示原生终端，归档保持只读。不同窗口共用运行时事实，各自保存草稿、阅读位置、选择和显示偏好。

终端复用同一 PTY 和原生状态。消息背景按原生终端列数与实际单元格处理，不把文本底色延伸到整行空白。观察、窗口聚焦、后台轮询和重连不取得尺寸；实际输入或原生控制后在前台保持尺寸，失焦、隐藏、离开或断连时释放。输入法提交与粘贴保留原文，断线不重放输入。

界面状态栏显示执行状态、实际原生提示、耗时和已有账号、模型、推理强度、额度、目录与上下文。详情按需展开，读取旧状态不隐式执行查询命令。错误留在相关操作区域，不添加系统推送或通知气泡。

## 文件

会话文件列表与搜索中的文件直接进入同一个文件页，复用已有标签、预览与编辑器；返回时恢复会话文件列表。代码框、源码预览与编辑器使用终端的 Cascadia Mono 英文字体和共用语法配色。Markdown 正文及目录沿用左栏的细滚动条，目录宽度可拖动或用方向键调整，并按根目录保存；Home 恢复默认宽度。

文件页提供工作区目录树、文件标签、全文复制和原位 UTF-8 源码编辑。Markdown 与代码文件均按源码修改，提供语法高亮、行号、缩进、查找和撤销重做；保存保留编辑器、光标和阅读位置，保存期间继续输入的内容仍标记为未保存。Markdown 支持拖动阅读宽度和右侧目录。保存核对读取版本，外部修改、路径变化和读取失败时显示明确反馈；不以截断预览覆盖完整文件。

会话附件和原生存档继续只读。文件读取、搜索、预览、编辑与目录扫描具有独立生命周期，不阻塞终端或会话切换。

## 更新

客户端更新位于全局设置；服务器版本、检查与下载入口归属于对应服务器。升级保留连接、会话、草稿与阅读位置。公开下载通道不参与业务连接。

## 恢复与可访问性

缓存优先显示，网络恢复后按身份与版本追平。短暂中断静默重连，认证或明确操作失败及时反馈。后台继续更新必要状态，停止绘制；一个窗口的阅读或显示选择不改变另一个窗口。

控件支持清晰标签、键盘操作、触摸目标与焦点。主题、字体、尺寸和减少动态效果适配保留消息身份、草稿、阅读位置和已就绪输入。

界面以系统字体呈现导航和正文，以 Cascadia Mono 呈现代码。默认界面基准字号为 14px；聊天与 Markdown 正文为 16px、1.75 倍行高，次要界面内容为 13px，辅助信息为 12px。代码阅读使用 13px、1.7 倍行高，行内代码相对正文缩放。字号设置按比例调整这些角色，终端保留独立字号。

聊天与 Markdown 默认阅读宽度不超过 40 个正文字号，窄窗口使用可用宽度；用户手动调整的阅读宽度优先。标题、正文、列表与辅助信息用字重及间距区分，侧栏行随文字自然增高。段落不使用两端对齐，代码和表格保留各自的滚动与换行能力。

实现边界见[架构](ARCHITECTURE.md)和[共享运行时约束](SHARED_RUNTIME_ARCHITECTURE.md)，实际平台覆盖按[验证流程](VALIDATION.md)记录。

Windows 冷启动先显示恢复位置和尺寸的主题窗口，再呈现本地首屏。关闭最后一个窗口时退出，初始化期间关闭不会随后重新弹窗。
