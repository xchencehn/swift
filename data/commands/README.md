# 本机版本对应的内置命令目录

这些文件来自对应版本 CLI 的原生 `/` 候选菜单，不从网页文档或其他版本猜测命令。

- Codex 0.162.1 的隔离 PTY 默认菜单中确认了 49 项候选；采集使用当前仍在运行的同版本二进制，未重启原会话。
- Codex 0.163.0 的隔离 PTY 默认菜单中确认了 52 项候选。账号与功能开关可能额外启用命令，Swift 已接通的设置操作单独补充。
- Codex 0.155.1 的独立 PTY 菜单中确认了 49 项。
- Claude Code 2.1.258 的独立 PTY 菜单中确认了 79 项内置命令；项目技能和插件命令由运行时 SDK initialize 补充，不把用户的技能副本写入这里。

采集时只输入 `/` 并用方向键遍历，不执行任何候选命令。Claude 使用已受信任的目录并关闭 hooks，遇到目录信任提示不得自动确认。菜单里的当前模型、sandbox 状态等会话值从说明中去掉，避免把采集会话的状态展示给其他会话。

读取方优先对会话实际运行的 Codex `/proc/<pid>/exe` 执行 `--version`；没有进程证据时明确使用本机安装版本来源，只接受同版本文件。升级时重新核对原生菜单并添加对应版本；版本不匹配时返回明确提示，禁止无条件复用旧目录。命令是否可用还可能受 CLI 功能开关、账户或会话状态影响，最终执行仍由 CLI 判断。

- Codex 0.164.0、0.165.0、0.166.0各在独立临时HOME和真实PTY中确认了54项原生菜单命令，包含goal、presets及受管扩展hfork。采集只输入斜杠并用方向键遍历，未执行候选或创建模型请求。当前网页另外提供effort设置入口；账户、平台及功能开关仍由实际CLI决定。
- 已有受管二进制可用`node scripts/testing/collect-command-catalog.js /绝对路径/bin/codex ...`重新采集，输出留在当前任务artifacts，人工核对后新增同版本目录；不在输入、切换或普通观察时启动采集。
